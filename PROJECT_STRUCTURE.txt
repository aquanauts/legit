Quick Commands:
---------------
Build:          docker build -t git-server:latest .
Start:          docker-compose up -d
Test:           ./test-setup.sh
Create repo:    docker exec git-server /usr/local/bin/init-repo.sh <name>
List repos:     docker exec git-server ls -la /srv/git
View logs:      docker logs git-server

Or use Makefile:
---------------
make help       - Show all commands
make quickstart - One-command setup
make test       - Run automated tests
make start      - Start the server
